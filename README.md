# Site de Refeel

Le site de l'application Refeel, en ligne sur https://getrefeel.app (hébergé gratuitement par GitHub Pages).

- `index.html` : accueil · `confidentialite/` · `conditions/` · `aide/`
- `en/` : les mêmes pages en anglais
- `style.css` : reprend la charte de l'app (fond pêche, cartes en verre, police Newsreader, corail)
- `CNAME` : le nom de domaine
